退党证书

证明办理

退党证明是一份由本中心签发的中英文对照文件，载明声明人姓名、退出的组织、声明日期与证明编号。它证明的是「此人已在本中心登记声明退出」这一事实。

请注意 退党证明由本中心签发，不是任何政府机关出具的文件，也不构成对移民申请结果的任何保证。是否采信、如何采信，由受理机构自行判断。请勿相信任何声称可以「加急」「包过」的收费服务——本中心所有服务均免费。

办理需要什么

你需要先完成一份三退声明。如果此前已经声明过，可以凭当时的声明信息申请补发。办理不需要提供身份证件，但你填写的姓名将原样印在证明上。

多久可以拿到

电子版通常在数个工作日内签发，由志愿者人工核对后发出。纸本证明可在服务点现场领取，或在特定活动现场颁发。
