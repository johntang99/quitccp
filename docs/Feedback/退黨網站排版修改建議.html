給工程師的 CSS 變量

放進全局樣式，再把現有的零散數值逐一替換成這些變量。

/* 1. 用 next/font/google 真正加載字體（在 layout.tsx）：
   Noto_Serif_SC({ weight: ['600','700'] })
   Noto_Sans_SC({ weight: ['400','500','700'] })
   繁體版另加 Noto_Serif_TC / Noto_Sans_TC */

:root {
  --serif: "Noto Serif SC", "Songti SC", serif;   /* 不要把 SimSun 當後備 */
  --sans:  "Noto Sans SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
  --mono:  "IBM Plex Mono", ui-monospace, monospace;  /* 只用於純數字和英文 */

  --fs-display: clamp(30px, 4vw, 48px);
  --fs-h2:      clamp(26px, 3vw, 36px);
  --fs-h3:      clamp(20px, 2vw, 24px);
  --fs-item:    18px;
  --fs-body:    17px;
  --fs-small:   14px;
  --fs-label:   13px;   /* 全站最小字號 */

  --lh-heading: 1.3;
  --lh-item:    1.5;
  --lh-body:    1.8;
}

@media (max-width: 640px) { :root { --fs-body: 16px; --fs-item: 17px; } }

body { font: 400 var(--fs-body)/var(--lh-body) var(--sans); letter-spacing: .02em; }

h1, h2, h3 {
  font-family: var(--serif);
  font-weight: 700;              /* 取代全站的 900 */
  line-height: var(--lh-heading);/* 標題不要沿用內文行距 */
  letter-spacing: .01em;
  text-wrap: balance;
}
h3 { line-height: 1.4; }

p { max-width: 38em; text-wrap: pretty; }

.eyebrow, .chip, .tag {
  font: 500 var(--fs-label)/1.6 var(--sans);  /* 不用等寬字體排中文 */
  letter-spacing: .08em;
}

.num, time, .stat { font-family: var(--mono); font-variant-numeric: tabular-nums; }

:lang(zh) { line-break: strict; text-spacing-trim: normal; }
.nw { white-space: nowrap; }  /* 包住專有名詞，防止拆行 */
7

驗收清單

改完後逐項檢查，Mac 和 Windows 都要看。

  • Windows 上標題不再是 SimSun。開發者工具 Network 裏能看到 Noto 字體文件載入。
  • CSS 裏搜不到 font-weight: 900。
  • 所有 h1–h3 的行距在 1.25–1.4 之間。
  • 內文只有一個行距 1.8。
  • 沒有小於 12px 的字號。
  • 中文不再使用 IBM Plex Mono。
  • 中文字距都不超過 0.1em。
  • 文案裏沒有用空格代替標點。中英文和數字之間是否空格，全站統一。
  • 標題在 390px 手機寬度下不會拆開專有名詞。
  • 簡體頁不混用繁體 Logo。另設 zh-Hant 繁體版，<html lang> 分別標記。
  • 窄屏下語言列和 Logo 有左右邊距。
  • 每個統計數字都有來源和更新日期。

左側樣本用各平台現有的後備字體模擬「字體未加載」的效果，所以在不同電腦上看會略有差異，這正是現在網站的問題所在。
