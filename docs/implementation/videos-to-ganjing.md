## 为什么要迁

这 **212 个视频**目前以 `.mp4` 文件形式托管在 `www.tuidang.org/wp-content/`，
合计 **47.6 GB**。两个问题：

1. **主域名切换后它们就没了。** `/wp-content/` 由老站的 WordPress 提供，主域名一旦
   指向新站，这些地址全部失效。
2. **流量成本。** 自己托管意味着每次播放都要付带宽。平均单个 230 MB，
   一次完整播放就是这个量。

站内其余视频早就是这个做法——**503 个用 YouTube 嵌入、7 个用干净世界**。这 212 个
是唯一还在自托管的一批。迁到干净世界后：不占存储、不耗流量、不受主域名切换影响。

## 迁移后怎么更新

干净世界地址拿到后，只需要把 `cms_videos.source_url` 换掉，**页面、分类、封面、
正文都不用动**。

- 少量：后台 → 视频管理 → 打开该条 → 改地址 → 保存
- 批量：把 CSV 最后一列「干净世界地址」填好发我，我写脚本一次性导入

地址格式参照站内已有的 7 条，例如：

```
https://www.ganjingworld.com/video/V4ByxZ6n2Svyy
https://www.ganjingworld.com/zh-CN/embed/1gaik5qofb75GB5sk3KbqlF5e1op1c
```

同目录 `videos-to-ganjing.csv` 是同一份数据的表格版，可直接用 Excel 打开分工认领。
