## 先说三件事

1. **旧站没有独立的「视频」内容类型。** 查过 `/wp-json/wp/v2/types`，只有
   post / page / attachment / docs 等，视频就是普通文章，靠分类区分。
2. **「视频类」分类里也不全是视频。** 610 篇里只有 216 篇正文带播放器（35%）。
3. **播放器几乎全是 YouTube**：217 个 YouTube，4 个干净世界。

另外约 **440 篇**带播放器的文章分散在别的分类下，比例最高的几个：

| 义工风采 `ygfc` | 5 / 14 |

| 打倒中共恶魔 `ddzgem` | 51 / 191 |

| 今日头条 `toutiao` | 42 / 617 |

也就是说：**「哪些是视频」不能只看分类**。如果按分类搬，会漏掉这四百多篇；
如果按「正文有没有播放器」搬，又会把新闻报导里顺带嵌的片子也算进来。
