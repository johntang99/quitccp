## 一、已经修好的

### 1. 公开页面上的分类全站都是错的
每一篇文章的页面都标着「国际声援行动」。文章模板在 payload 没给 tag 时默认
用这个字符串，而 payload 从来就没给过——`getRenderableArticle` 只看页面列表
条目和原型种子，**从没查过文章自己的分类**。默认值恰好是一个真实栏目名，
所以看起来像事实而不像占位符。
→ 现在从分类表 position 0 取真实分类，模板默认改成中性的「新闻与报告」。

### 2. 每篇文章正文末尾多了一句排版说明
15,514 篇文章的最后一段都是
「正文中的链接使用紫色并带下划线，在浅色背景上保持足够对比度。」
这是设计稿演示链接样式用的句子，被无条件渲染成了正文的一部分。
→ 已移除（模板默认和种子 payload 两处都要清）。

### 3. 每篇文章页面都挂着两篇编造的「相关文章」
「欧洲议会通过决议，关注强制器官摘取问题」（2026-06-25 · 布鲁塞尔）和
「美国第 444 号决议与华人身份申请的关系」——都有日期、有地点，都不存在。
→ 改成从同分类里取真实文章。

### 4. 新闻归档模板里藏着一条编造的头条
「美议员在国会表彰退党运动」，点名田纳西州众议员安迪·奥格尔斯，
称表彰「正式载入《国会议事录》」。目前没渲染出来（CMS 有自己的头条），
但任何一次没带头条的保存都会把它当成本站报导发出去。
→ 已清空。

**这三条是同一个毛病**：原型的占位内容写成了真实的人名、日期、机构名。
对一个以可查证为立身之本的站点，占位符看起来像事实比留白危险得多。

### 5. 后台列表日期乱跳、翻页会重复
排序用 `updated_at`，而导入是分批写的，**每 80 篇共用同一秒**，
组内顺序由数据库随便给。日期从 2026 跳到 2011 就是这么来的，
OFFSET 翻页也因此会漏会重。
→ 每个排序下面都加了 `id`，默认排序改成发布时间。文章和视频两边都改了。

### 6. 「状态」栏看着是空的
表格比容器宽，`width:100%` 没有溢出容器，浏览器就去挤列宽，
「已发布」被挤成一列一个字贴在最右边——你的截图右边缘那三个竖排的字就是它。
→ 宽表格改成横向滚动。

### 7. 视频库有 745 个节目，但站上没有入口
`/videos` 链到八个分类页，**八个全是 404**；只有拼对完整视频 slug 才能看到
一个视频。首页本身还是一张 CMS 页，列着五个手写栏目（其中两个不是现有分类，
另外三个现有分类没列），没有一个真实节目。
→ 分类页做了（封面、时长、翻页），首页改成按真实数据渲染八个栏目。

### 8. 视频后台
点任何视频都 404（`/admin/videos/[id]` 根本没建）、日期全是导入当天、
「来源」只写「播放」不说在哪、没有预览、没有删除。
→ 编辑页、新建页、表单、保存接口都补上了；来源改成写明宿主
（YouTube／干净世界／自有（旧站）／无地址）；加了预览和删除；
发布改成「发表／存草稿」两个按钮；正文换成和文章一样的 Markdown 编辑器。

### 9. REST 看不到的播放器
旧站的视频是用 Elite Video Player 的 Elementor 短代码放的，
地址只存在于渲染后的页面上，REST 的 `content.rendered` 里一点痕迹都没有。
你指出九评之八明明有播放器，就是这个原因。
→ 抓回 213 个自托管 .mp4 地址，另从媒体库取回 201 个时长。
745 个里 725 个现在有播放地址。

### 10. 待归类 227 篇
→ 219 篇按内容归好（三退系列进三退要闻，九评进专题报导，
第一人称口述进退党纪实故事），剩 8 篇留给人判断。

### 11. 首页滚动的十条「三退声明」是编的
「伍万＊ · 中国大陆」「李＊明 · 中国大陆」这些，连声明编号
（No. 464,375,381）和日期都写得像真的。**和第 3、4 条是同一个毛病**，
而且更危险：它们冒充的是真人做出的声明，而这正是本站的立身之本。
→ 改成从 santui.tuidang.org 的「精彩推荐」同步真实声明，数字也从
`/stat/statics` 取实时值（4.64 亿写死 → 4.66 亿自动更新）。
每小时跑一次，详见 [santui-registry-sync.md](./santui-registry-sync.md)。
`HomeTemplate.tsx` 里的占位数组只在一次都没同步过时才会用到。

### 12. 首页「我们的服务」卡片里有死链
「迫害案例档案」「调查报告」指向 `/news/investigations`，
「国际议会与机构关注」指向 `/news/solidarity`——**这两个地址都是 404**，
是旧站的栏目划分，新站没有。另有两条还指着 tuidang.org。
→ 全部改到新站的真实分类；「专题栏目」里同样的两个死链一并修了。
第一张卡片（三退登记与证明）按你的要求保持原样，仍指向 santui 与 service。

## 二、正在跑

### 作者
你说得对，文章都有作者，是 REST 拿不到——旧站主题把署名渲染进
Elementor 的 post-info 里，`content.rendered`、`acf`、`meta` 全都没有。
`scripts/harvest-authors.ts` 从渲染页上读，两种格式都认：
`文／陈光诚｜著名维权人士` 和 `（退党中心记者 黄真报导）`。

抽样命中率约 45%，15,471 篇要跑十几个小时。**可以随时中断重来**——
它只找 author 为空的文章，边跑边写。有些页面确实没有署名（只有「浏览量」），
那部分补不上。
