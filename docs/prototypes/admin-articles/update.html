这一页的规则

  1. 搜索与筛选都写进网址，可以把某个筛选结果的链接发给同事，也能加书签。
  2. 点标题进编辑页；编辑页保存后回到原来的筛选结果与页码，不会把人甩回第一页。
  3. 删除默认劝阻：已发布的文章先建议归档，并告知有多少站内链接会断。
  4. 数据质量筛选（缺封面／缺作者／缺摘要／未分类）是为迁移进来的一万篇旧文准备的——大部分没有封面与署名。
