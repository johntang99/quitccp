导入时每个视频会带上什么

字段从哪里来
标题、发布日期旧站文章原样搬
视频地址正文里 ::: video 块的第一个地址
简介正文去掉播放器之后的文字，截前 300 字
封面旧站文章的封面图；没有就去视频平台抓，都下载进我们的桶
分类按左边那张表的规则
旧站地址原样保留，用来做 301 跳转
集数从标题里认「第 N 集／第 N 期」，认不出就留空
导入的视频同时还是文章吗？不是。进了视频库就从文章列表里撤下来， 否则同一篇东西在站内出现两次，搜索结果里也会重复。 旧地址照常 301，只是落到 /videos/… 而不是 /news/…。 这一条需要你点头，因为它会让文章总数从 15,514 减到 14,799。
