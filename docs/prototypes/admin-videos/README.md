# 视频管理设计稿

从 `index.html` 开始，顶部标签页可以走完五个页面。样式表和文章管理共用
（`../admin-articles/admin.css`），因为两个后台要长得一样。

| 文件 | 页面 |
|---|---|
| `index.html` | 设计说明、待定事项 |
| `new.html` | A · 新建视频 |
| `update.html` | B · 查找与修改 |
| `latest.html` | C · 最新 100 个 |
| `status.html` | D · 视频统计 |
| `import.html` | E · 从旧站导入（文章管理没有这一页） |

页面里的数字是真的，取自 `artifacts/phase5/video-allocation.json`；
视频标题和封面是示意。
