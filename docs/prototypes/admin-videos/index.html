这份设计稿

结构照搬文章管理，编辑学一次就会用两个。差别全部来自「视频是外站的、文章是我们的」这一条。

五个页面

页面做什么和文章的差别
A · 新建视频 贴地址 → 自动读取 → 改一改 → 发布 以视频地址开头而不是标题；封面自动抓；没有 16 键 Markdown 编辑器
B · 查找与修改 搜索、筛选、批量改、删除 多了「播放地址失效」筛选和来源平台筛选
C · 最新 100 个 直接列出最近改动的 100 个 无
D · 视频统计 总量、各分类、各平台、各年份 多了失效计数和总时长；按平台分布是视频独有的
E · 从旧站导入 把旧站挑出来的 715 个搬进视频库 文章管理没有这一页。旧站没有视频类型，得先挑再搬

三个我认为值得单独说的决定

  1. 新建视频从「贴地址」开始，不是从「填标题」开始。 九成的字段能从视频平台读出来，让编辑先贴地址，后面就只剩选分类。 反过来做的话，每个视频都要手打标题、找封面、量时长。
  2. 封面一律下载进我们自己的桶。 YouTube 的缩略图地址在大陆打不开，而且视频一下架缩略图就跟着没了。 这和文章图片的处理是同一条规则。
  3. 「播放地址失效」要当成一个日常指标，不是一次性检查。 文章搬过来就永远在，视频不是——YouTube 随时可能下架一个频道。 每周自动抠一遍，失效的进 B 页的筛选器和 D 页的红字。

等你定的四件事

  1. 350 个「带标注」的要不要导入？ 导：视频库 715 个，但其中 324 个堆在其它系列。 不导：365 个，干净，但只有四个栏目有内容。我倾向导——它们的播放器都是活的。
  2. 破除党文化（0）、退一步海阔天空（2）、觉醒之旅（4）怎么开张？ 先隐藏，还是从别处调内容？
  3. 进了视频库的，要不要从文章列表撤下来？ 我认为要，否则站内重复。代价是文章数从 15,514 变成 14,799。
  4. 681 个 YouTube 视频，大陆读者看不到。 要不要给每个配一个干净世界的备用地址？这是内容工作不是技术工作，量不小。
